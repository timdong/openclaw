# OpenClaw 开源搜索方案

## 概述

OpenClaw 目前默认只支持 Brave Search 和 Perplexity（都需要 API key）。本文档提供两种开源、免费的搜索方案：

1. **DuckDuckGo 插件**（推荐）- 通过插件系统添加，不修改核心代码
2. **修改核心代码** - 直接在 `web_search` 工具中添加 DuckDuckGo 支持

## 方案一：DuckDuckGo 插件（推荐）

### 优点
- ✅ 不修改核心代码，易于维护
- ✅ 可以独立更新
- ✅ 不影响现有功能

### 安装步骤

1. **安装依赖**
```bash
cd extensions/duckduckgo-search
pnpm install
```

2. **启用插件**

编辑 `~/.openclaw/openclaw.json`：
```json5
{
  plugins: {
    entries: {
      "duckduckgo-search": {
        enabled: true
      }
    }
  }
}
```

3. **允许工具使用**

在 agent 配置中添加工具到 allowlist：
```json5
{
  agents: {
    list: [
      {
        id: "main",
        tools: {
          allow: ["duckduckgo_search", "web_search", "web_fetch"]
        }
      }
    ]
  }
}
```

4. **重启网关**
```bash
pnpm openclaw gateway stop
pnpm openclaw gateway run --port 18789
```

### 使用

配置完成后，助手可以使用 `duckduckgo_search` 工具进行搜索：

```
请搜索：A股大盘成交量 2026年2月最新走势
```

## 方案二：修改核心代码添加 DuckDuckGo

### 优点
- ✅ 统一使用 `web_search` 工具
- ✅ 与现有配置系统集成

### 缺点
- ⚠️ 需要修改核心代码
- ⚠️ 更新 OpenClaw 时可能需要重新应用修改

### 实现步骤

1. **安装依赖**
```bash
pnpm add duck-duck-scrape
```

2. **修改 `src/agents/tools/web-search.ts`**

在文件开头添加：
```typescript
import { search as duckDuckGoSearch } from "duck-duck-scrape";
```

修改 `SEARCH_PROVIDERS`：
```typescript
const SEARCH_PROVIDERS = ["brave", "perplexity", "duckduckgo"] as const;
```

在 `runWebSearch` 函数中添加 DuckDuckGo 处理逻辑（在 Perplexity 之后，Brave 之前）：
```typescript
if (params.provider === "duckduckgo") {
  const results = await duckDuckGoSearch(params.query, {
    safeSearch: "moderate",
    region: params.country?.toLowerCase() || "us",
  });

  const mapped = results.results.slice(0, params.count).map((result: any) => ({
    title: result.title || "",
    url: result.url || "",
    description: result.description || "",
    icon: result.icon || undefined,
  }));

  const payload = {
    query: params.query,
    provider: params.provider,
    count: mapped.length,
    tookMs: Date.now() - start,
    results: mapped,
  };
  writeCache(SEARCH_CACHE, cacheKey, payload, params.cacheTtlMs);
  return payload;
}
```

修改 `resolveSearchProvider` 函数，添加 duckduckgo 支持：
```typescript
function resolveSearchProvider(search?: WebSearchConfig): (typeof SEARCH_PROVIDERS)[number] {
  const raw =
    search && "provider" in search && typeof search.provider === "string"
      ? search.provider.trim().toLowerCase()
      : "";
  if (raw === "perplexity") {
    return "perplexity";
  }
  if (raw === "duckduckgo") {
    return "duckduckgo";
  }
  if (raw === "brave") {
    return "brave";
  }
  return "duckduckgo"; // 默认使用 DuckDuckGo（免费）
}
```

修改 `createWebSearchTool` 中的描述：
```typescript
const description =
  provider === "perplexity"
    ? "Search the web using Perplexity Sonar (direct or via OpenRouter). Returns AI-synthesized answers with citations from real-time web search."
    : provider === "duckduckgo"
      ? "Search the web using DuckDuckGo (free, no API key required). Returns search results with titles, URLs, and snippets. Privacy-friendly."
      : "Search the web using Brave Search API. Supports region-specific and localized search via country and language parameters. Returns titles, URLs, and snippets for fast research.";
```

修改 `missingSearchKeyPayload` 函数：
```typescript
function missingSearchKeyPayload(provider: (typeof SEARCH_PROVIDERS)[number]) {
  if (provider === "duckduckgo") {
    return {
      error: "duckduckgo_no_key_needed",
      message: "DuckDuckGo search does not require an API key.",
      docs: "https://docs.openclaw.ai/tools/web",
    };
  }
  // ... 其他代码保持不变
}
```

3. **更新配置类型**

修改 `src/config/types.tools.ts`：
```typescript
provider?: "brave" | "perplexity" | "duckduckgo";
```

4. **配置使用 DuckDuckGo**

编辑 `~/.openclaw/openclaw.json`：
```json5
{
  tools: {
    web: {
      search: {
        provider: "duckduckgo",
        enabled: true
        // 不需要 apiKey
      }
    }
  }
}
```

5. **重新构建**
```bash
pnpm build
```

6. **重启网关**

## 对比

| 特性 | DuckDuckGo | Brave Search | Perplexity |
|------|-----------|-------------|------------|
| 费用 | 免费 | 免费层可用 | 付费 |
| API Key | 不需要 | 需要 | 需要 |
| 隐私 | 高 | 中等 | 中等 |
| 结果质量 | 良好 | 优秀 | 优秀（AI 合成） |
| 中文支持 | 是 | 是 | 是 |

## 推荐方案

- **个人使用/测试**：使用方案一（插件），简单快速
- **生产环境**：如果已有 Brave API key，继续使用 Brave；否则使用方案一（插件）

## 其他开源搜索方案

### SearXNG（自建）

SearXNG 是一个开源元搜索引擎，可以自建实例：

1. 部署 SearXNG 实例（Docker 最简单）
2. 创建一个插件调用 SearXNG API
3. 配置为搜索提供商

### 使用浏览器工具

如果只需要偶尔搜索，可以使用 OpenClaw 的 `browser` 工具：
- 打开搜索引擎网页
- 执行搜索
- 提取结果

但这种方式较慢，不适合频繁使用。

## 故障排除

### DuckDuckGo 搜索失败

- 检查网络连接
- DuckDuckGo 可能有速率限制，稍后重试
- 检查 `duck-duck-scrape` 包是否正确安装

### 插件未加载

- 检查插件是否在 `plugins.entries` 中启用
- 检查 `extensions/duckduckgo-search/package.json` 是否存在
- 查看网关日志：`tail -f /tmp/openclaw/openclaw-*.log`
