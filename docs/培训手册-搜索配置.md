# OpenClaw 互联网搜索功能配置指南

## 问题说明

当前 OpenClaw 的 `web_search` 工具未配置 API key，因此无法进行互联网搜索。助手会提示"没有实时行情的接口"。

## 解决方案

OpenClaw 支持两种搜索提供商：

### 方案一：Brave Search（推荐，有免费层）

**优点：**
- 提供免费层
- 快速、结构化搜索结果
- 支持地区特定搜索

**配置步骤：**

1. **获取 API Key：**
   - 访问 https://brave.com/search/api/
   - 注册账号并登录
   - 在 Dashboard 中选择 **"Data for Search"** 计划（注意：不是 "Data for AI"）
   - 生成 API Key

2. **配置 API Key（两种方式任选其一）：**

   **方式 A：使用配置向导（推荐）**
   ```bash
   pnpm openclaw configure --section web
   ```
   然后按提示输入 Brave Search API Key

   **方式 B：手动配置**
   ```bash
   pnpm openclaw config set tools.web.search.apiKey "你的_BRAVE_API_KEY"
   ```

   **方式 C：使用环境变量**
   在 `~/.openclaw/.env` 文件中添加：
   ```
   BRAVE_API_KEY=你的_BRAVE_API_KEY
   ```

3. **重启网关：**
   ```bash
   pnpm openclaw gateway stop
   pnpm openclaw gateway run --port 18789
   ```

### 方案二：Perplexity Sonar（AI 合成答案）

**优点：**
- AI 合成的答案，带引用来源
- 实时网络搜索
- 适合复杂问题

**缺点：**
- 需要付费（可通过 OpenRouter 使用加密货币/预付费）

**配置步骤：**

1. **获取 API Key：**

   **选项 A：Perplexity 直接 API**
   - 访问 https://www.perplexity.ai/
   - 注册并获取 API Key（格式：`pplx-...`）

   **选项 B：OpenRouter（推荐，支持加密货币）**
   - 访问 https://openrouter.ai/
   - 注册账号并充值（支持加密货币、预付费或信用卡）
   - 生成 API Key（格式：`sk-or-v1-...`）

2. **配置：**

   ```bash
   pnpm openclaw config set tools.web.search.provider "perplexity"
   pnpm openclaw config set tools.web.search.perplexity.apiKey "你的_API_KEY"
   ```

   如果使用 OpenRouter：
   ```bash
   pnpm openclaw config set tools.web.search.perplexity.baseUrl "https://openrouter.ai/api/v1"
   ```

   或者使用环境变量（在 `~/.openclaw/.env`）：
   ```
   PERPLEXITY_API_KEY=pplx-...  # 或
   OPENROUTER_API_KEY=sk-or-v1-...
   ```

3. **重启网关**

## 验证配置

配置完成后，在 OpenClaw Dashboard 中测试：

```
请搜索：A股大盘成交量 2026年2月最新走势
```

如果配置正确，助手应该能够使用 `web_search` 工具搜索并返回结果。

## 查看当前配置

```bash
# 查看搜索配置
pnpm openclaw config get tools.web.search

# 查看完整配置
pnpm openclaw config get tools
```

## 其他搜索相关工具

OpenClaw 还提供 `web_fetch` 工具（默认启用，无需 API Key）：
- 用于获取网页内容
- 将 HTML 转换为可读的 Markdown/文本
- 不支持 JavaScript 执行（需要浏览器工具）
